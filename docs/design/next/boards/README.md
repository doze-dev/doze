# Boards

The dash is built from these. Each file is one artboard of the canvas at
https://claude.ai/artifact/2wonaARTbNUxwRM6K26Sko, saved as published. term.css is
the palette and the type; Main.dc.html is Home, Focus.dc.html is a database module,
Narrow.dc.html is 80x24.

A screen is done when a frame rendered at the board size has been put beside its
board and the person who drew the board agrees. A golden is checked in only after.

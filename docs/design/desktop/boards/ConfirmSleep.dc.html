Sleep db?

Two things are awake because of db. Putting it to sleep puts them to sleep too, in reverse order; the next connection to any of them wakes it all again, and nothing is lost.

apineeds db · runs until stopped, so it will wake db back in a moment
webneeds db · pinned, so it will too
4 connectionsopen clients get disconnected; most reconnect

Since api runs until stopped and web is pinned, db would wake again almost at once. To keep it down, sleep api and web as well, or turn db off for this run.

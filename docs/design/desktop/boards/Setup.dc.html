Later
Step 2's prompt is the system's own: the password or Touch ID dialog on macOS; polkit (pkexec) on Linux, where the names setup is the doze-names service and a sysctl file. It runs doze-names' script, the same as doze doctor --fix.
Already set up? If the CLI did it before, the app checks (names.Check) and skips step 2. If an OS update removes part of it later, Settings offers a repair. Uninstall is in Settings too.
Linux: the same four steps. Start at login is an XDG autostart file. With no tray (stock GNOME), the window opens at login instead and notifications carry the rest.

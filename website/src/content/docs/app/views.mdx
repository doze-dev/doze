Four views of the same stack. Pick one with the switch at the top, or press
<kbd>1</kbd> to <kbd>4</kbd>. doze remembers the view for each stack.

Beside the view switch, **Activity** (<kbd>A</kbd>) reads the stack's journal
over the last hour, day or week: how long each service slept, about how much
memory that left free, what woke each one, and what crashed. **All logs**
(<kbd>L</kbd>) is every service's output, merged.

## Which view, for what

| View | What it shows | Use it to |
|---|---|---|
| **Tiles** <kbd>1</kbd> | A card per service, with its state, its memory and its address. | See at a glance what is awake. |
| **List** <kbd>2</kbd> | A row per service, and a details pane for the one you select. | Read addresses and details without opening each one. |
| **Map** <kbd>3</kbd> | Who calls whom, from references in doze.hcl. Click a card to draw its lines. | Understand a stack you did not write. |
| **Grid** <kbd>4</kbd> | The stack as a table: a row needs each column it has a dot in. | Answer "what uses kafka?" down a column. |

Tiles and List group the services the same way: **apps** (your code),
**modules** (from the doze registry), **outside** (your own services) and
**tasks**. Every row has a switch: on wakes the service, off puts it to sleep.
Putting a service to sleep asks first when something running depends on it.

## Keys

<Keys
  keys={[
    ["1–4", "Tiles, List, Map, Grid"],
    ["↑ ↓ j k", "move"],
    ["space", "wake or sleep the selected one"],
    ["⏎", "open it"],
    ["w s", "wake, sleep"],
    ["p", "pin it awake"],
    ["r", "restart it"],
    ["l", "its logs"],
    ["y", "copy its address"],
    ["/", "filter"],
    ["A L", "Activity, all logs"],
  ]}
/>

In the Map the arrow keys move between cards the way they are drawn. In the
Grid, an arrow key or <kbd>⏎</kbd> moves into the table, and <kbd>/</kbd>
filters its rows. Every key is listed under [⌘K and keys](/app/keys/).

### In a terminal

```sh
doze status            # every service, its state and memory
doze status --graph    # the dependency tree
```

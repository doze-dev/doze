Reach any stack, service or command from the keyboard, and look up every key.

Press <kbd>?</kbd> (or <kbd>⌘/</kbd>) anywhere in the app for the same list, and
for what each state word means.

## ⌘K: search or do

<kbd>⌘K</kbd>, or **Search or do** at the top right, opens the palette on every
page. It reaches across every stack on the machine.

<Shot src={palette} alt="The palette open on the larder stack with nothing typed: suggested commands, the two stacks, and Open folder" caption="Nothing typed: commands for the page you are on, then every stack." crop />

With nothing typed it shows what is broken, a few commands for the page on
screen, what you did lately, and every stack. A command that has a `doze` twin
shows it, such as `doze sleep`.

Type to search, then:

- **A name** finds a service or a stack. <kbd>⏎</kbd> opens it.
- **<kbd>tab</kbd> on a name** narrows the palette to its commands: restart,
  logs and the rest. <kbd>⇧tab</kbd>, or <kbd>⌫</kbd> in an empty box,
  steps back out.
- **A name, then words** is a command for it (`gateway restart`, `postgres psql`)
  or, when the words are not a command, a search of its logs (`gateway timeout`).
- **A verb, then a name** works too: `sleep postgres`, `logs gateway`.
- **`theme teal`** changes the colour theme.

A copy says so in place and leaves the palette open for the next thing.

When the stack is stopped, <kbd>space</kbd> starts it with the selected service,
<kbd>u</kbd> brings it up as last time, and <kbd>c</kbd> chooses what starts.

In the **Map**, the arrow keys move between cards the way they are drawn. In the
**Grid**, an arrow key or <kbd>⏎</kbd> moves into the table; there the arrows
move between cells, <kbd>⏎</kbd> opens the service of that column, <kbd>o</kbd>
opens the row, <kbd>space</kbd> wakes or sleeps it, and <kbd>/</kbd> filters
rows.

console tab has the keyboard, letters are the console's own actions.

## The same as commands

Every key is a `doze` command too, for scripts and CI:

```sh
doze sleep postgres      # s
doze wake postgres       # w
doze pin postgres        # p
doze restart gateway     # r
doze logs gateway        # l
doze url gateway         # y
```
